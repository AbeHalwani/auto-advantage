## Core Features Included
1. **Direct Click-to-Call Actions:** Integrated on navigation, hero, service cards, and sticky mobile call bar.
2. **Interactive Estimate Request:** Quick intake card on hero and detailed modal workflow (Year, Make, Model, Insurance Carrier, Damage description).
3. **All 7 Required Services:**
   - Collision Repair
   - Frame Repair & Alignment (Computerized 3D measuring)
   - Precision Body Painting (Climate-controlled downdraft booth)
   - Dent & Hail Repair
   - Windshield Replacement
   - Complete Mechanical Auto Repair
   - Direct Insurance Claims Assistance
4. **Hassle-Free Insurance Strip:** Direct billing with State Farm, Progressive, AAA Michigan, Geico, Allstate, Liberty Mutual, Farmers, Nationwide, USAA, and more.
5. **Lifetime Warranty Guarantee:** Highlighted collision workmanship and paint protection guarantee.
6. **Recent Work Gallery:** Before and after collision restoration cards.
7. **Customer Testimonials & FAQ:** Addressing deductible payments, repair timeframes, and rights under Michigan law.

## Running Locally / Previewing

You can preview the site immediately with any local HTTP server:

```bash
# Using Node / npx:
npx serve .

# Or using Python:
python3 -m http.server 3000
```

Open `http://localhost:3000` in your browser.
